Project Overview
This project is a responsive website updated from Part 1 to meet Part 2 requirements. The focus of Part 2 was implementing responsive design using CSS Flexbox, Grid, and media queries to ensure optimal user experience across desktop, tablet, and mobile devices.

Part 1 Updates Changelogs
-From the feedback of part 1, pages are fixed
- index.html updated header to use semantic <nav> and <header> tags
- All 5 pages linked updated styles.css and checked consistency
- Added srcset and sizes to all images for accessibility
- Validated HTML structure - no broken tags
CSS Variables & Consistency:
   - Added :root variables for primary colors, fonts and spacing
   - Applied consistent styling across all pages
 Responsive Design:
   - Added @media queries for mobile (max-width: 768px) and tablet (max-width: 1024px)
   - Adjusted navigation to stack on mobile
Layout Enhancement:
   - Implemented Flexbox for header and product cards
   - Implemented Grid for main content layout
   - Improved visual hierarchy with spacing and font sizes
Testing:
   - Tested on Chrome DevTools for desktop and mobile views
   - Screenshots captured for POE evidence

Part 2 Updates
- Implemented responsive layout using CSS Grid and Flexbox
- Added media queries for 3 breakpoints: Desktop (1920px), Tablet (768px), Mobile (375px)
- Improved semantic HTML structure (<header>, <nav>, <main>, <footer>)
- Added meta viewport tag for responsiveness: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- Optimized images and content prioritization for mobile users
- Tested website across different browsers and devices
